How Spritesheets Work

A worked example using Plant #4 from the Mayflowers game.

A spritesheet packs many small images (frames) into one big image. Instead of loading dozens of files, you load a single PNG and a small data file that says where each frame lives inside it. To play an animation, you draw one frame, then the next, then the next.

Plant #4 is stored as plant4.png (the pixels) plus plant4.json (the coordinates). The JSON was exported from Adobe Animate and holds 11 frames — a seedling growing into a full plant.

2. Reading one frame

Each entry in the JSON looks like this:

"frame": {"x":0,"y":146,"w":115,"h":110} — cut this rectangle out of the sheet. Because the frames are trimmed (empty space removed), "spriteSourceSize": {"x":10,"y":145} tells us where to paste that rectangle back inside the plant's full 129×255 box, so every frame lines up at the same base.

3. Play it

Press the button to draw frames 0 → 10 in sequence onto the canvas below. That is all an animation is: the right rectangles, in order.
